FROGTOD Affiliate Assistant
Terakhir diperbarui: 24 November 2026

1. Tentang aplikasi ini

FROGTOD Affiliate Assistant ("Aplikasi") adalah perangkat lunak yang dijalankan sendiri (self-hosted) oleh pemilik akun untuk mengelola konten afiliasi pada akun miliknya sendiri. Aplikasi berjalan di komputer/server pribadi pemilik akun, bukan layanan multi-pengguna, dan tidak memiliki server pusat.

Kontak: arifdaryanto.work@gmail.com

3. Data yang tidak diambil

  • Data pembeli, nomor telepon, atau alamat pengiriman.
  • Pesan pribadi (DM) dan data akun pengguna lain.
  • Data dari halaman publik platform melalui scraping.
  • Kata sandi akun platform mana pun.

4. Dasar pemrosesan

Pemrosesan dilakukan atas dasar persetujuan dan instruksi pemilik akun sendiri, yang juga pemilik perangkat tempat Aplikasi berjalan.

6. Pembagian data dengan pihak ketiga

Aplikasi tidak menjual dan tidak membagikan data ke pihak ketiga. Data hanya dikirim ke:

  • Platform yang dihubungkan pemilik akun (Meta, TikTok) melalui API resmi, sebatas konten yang disetujui untuk dipublikasikan.
  • Penyedia model bahasa yang dikonfigurasi pemilik akun — hanya teks produk dan draf konten. Token akses dan data akun tidak pernah dikirim ke penyedia model.

7. Keamanan

  • Token dan kredensial disimpan lokal dengan izin berkas terbatas.
  • Nilai rahasia disaring otomatis dari log dan pesan kesalahan.
  • API internal hanya mendengarkan di 127.0.0.1 (tidak terbuka ke internet).
  • Setiap tindakan tercatat dalam audit trail.
  • Tersedia tombol emergency stop yang menghentikan semua publikasi.

8. Hak pemilik akun

  • Menghapus seluruh data dengan menghapus folder data/ Aplikasi.
  • Mencabut akses kapan saja melalui pengaturan platform (Meta Business Integrations / TikTok).
  • Meminta salinan data dalam bentuk ekspor.

9. Anak-anak

Aplikasi tidak ditujukan untuk pengguna di bawah 18 tahun.

10. Perubahan kebijakan

Perubahan akan diperbarui pada halaman ini beserta tanggal pembaruan.

11. Penghapusan data (Data Deletion Instructions)

Untuk meminta penghapusan data: kirim email ke arifdaryanto.work@gmail.com dengan subjek Hapus Data. Permintaan diproses maksimal 7 hari kerja. Pemilik akun juga dapat menghapus seluruh data secara langsung dengan menghapus folder data/ pada perangkat tempat Aplikasi dipasang.
